# Kirby GB/GBC - Custom Emulator for Nintendo Switch

Это кастомный эмулятор Game Boy и Game Boy Color(Разработка) для Nintendo Switch, созданный на основе открытого кода **GameLad NX**. 
Проект был переработан и улучшен: добавлено собственное меню, настройки, смена цветовых тем и сплэш-экран.

## ✨ Что нового в этой версии (Custom by Yarik)
*   **Собственное меню выбора игр**: Теперь все ROM-файлы из папки отображаются списком (с прокруткой, если игр много).
*   **Смена цветовых тем**: Классический зеленый Game Boy, розово-фиолетовая тема Kirby и черно-белая тема.
*   **Настройки**: Возможность переназначить кнопки (A, B, Start, Select).
*   **Сплэш-экран**: Заставка с названием эмулятора и автором при запуске.
*   **Отображение времени**: В главном меню теперь показываются часы.
*   **Ускорение (Fast Forward)**: Зажмите **ZR** в игре для ускорения (в разработке).
*   **Выход в меню**: Зажмите **L + R + Plus** во время игры, чтобы вернуться к выбору ROM-ов (в разработке).

## 🛠️ Как собрать (Build)
Для сборки проекта вам понадобится **devkitPro** (devkitA64) и библиотеки **SDL2**.
1. Установите devkitPro и MSYS.
2. В терминале MSYS выполните команду для установки зависимостей:
   `pacman -S switch-sdl2 switch-sdl2_ttf switch-sdl2_mixer switch-sdl2_image switch-sdl2_gfx`
3. Перейдите в папку с проектом и введите:
   `make`
4. Готовый файл `.nro` появится в папке с проектом.

## 🎮 Как играть (Installation)
1. Скачайте готовый файл **`KirbyGB.nro`** из раздела **Releases**.
2. Поместите его на карту памяти Switch по пути: `sd:/switch/`.
3. Создайте папку для игр: `sd:/switch/KirbyGB/roms/` и закиньте туда свои `.gb` и `.gbc` файлы.
4. Для запуска цветных игр (GBC) может потребоваться файл BIOS. Положите его по пути: `sd:/switch/KirbyGB/gbc_bios.bin`.
5. Запустите эмулятор через **hbmenu** (зажав R при запуске любой игры).
